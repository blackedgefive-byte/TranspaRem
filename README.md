# 🖼️ TranspaRem — AI背景透明化ツール

<p align="center">
  <strong>AIが画像の背景を自動で透明化する Windows向けデスクトップアプリ</strong>
</p>

---

## ✨ 特徴

- 🤖 **AI自動処理** — ワンクリックで背景を自動除去
- 📂 **一括処理** — 複数ファイル・フォルダごとまとめて処理
- 🖱️ **ドラッグ＆ドロップ** — ファイルをウィンドウに落とすだけ
- 🖌️ **手動微調整** — 消しゴム＆復元ブラシで細かい修正が可能（Undo対応）
- 🎨 **5種類のAIモデル** — 用途に合わせて選択可能
- 📐 **リサイズプリセット** — メルカリ・Instagram・YouTube・LINEスタンプ等に対応
- 🌓 **色調補正** — 明るさ・コントラストの調整
- 🔲 **ドロップシャドウ** — 影エフェクトの追加
- 💾 **PNG / WebP対応** — 透過画像をそのまま保存

---

## 🚀 インストール・使い方

### ダウンロード

1. [**Releases**](../../releases) ページから最新版のZIPファイルをダウンロード
2. ZIPを解凍
3. `TranspaRem.exe` をダブルクリックで起動

> **⚠️ 初回起動時の注意**
> Windows SmartScreen の警告が表示される場合があります。
> 「詳細情報」→「実行」をクリックしてください。

### 基本的な使い方

1. アプリを起動
2. 画像ファイルを**ドラッグ＆ドロップ**、または「ファイルを選択」ボタンをクリック
3. 「**透明化を実行(一括)**」ボタンをクリック
4. 処理結果を確認し、必要に応じて「🖌️ 手動で微調整」で修正
5. 自動保存 or 「手動で保存」で保存

## 🤖 AIモデル一覧

| モデル | 特徴 | 初回DLサイズ |
|--------|------|-------------|
| **標準（u2net）** | 何でも使える汎用モデル | 約170MB |
| **高速（u2netp）** | 速さ優先（精度は低め） | 約4MB |
| **人物専用** | 人・顔の切り抜きに最適 | 約170MB |
| **高精度** | 丁寧だが処理に時間がかかる | 約170MB |
| **シルエット** | 影・輪郭の抽出向け | 約43MB |

> AIモデルは初回使用時に自動ダウンロードされます。2回目以降はオフラインで動作します。
